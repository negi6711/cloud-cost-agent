# Cloud Cost Decision Snapshot (MVP 0)

> Upload your AWS billing data and receive a ranked Cloud Cost Decision Snapshot: what changed, why
> it changed, who owns it, what action is safest, and what evidence is missing.

MVP 0 is **read-only**. It never asks for AWS credentials, never calls AWS APIs, and never changes
infrastructure. It accepts an AWS Cost Explorer CSV export, computes deterministic facts, asks
TypeSafe **Jev** bounded typed questions about each candidate finding (only with the user's
consent), applies a deterministic policy gate, and renders a snapshot.

## Hard invariants

1. **Deterministic code owns every number.** Parsing, totals, deltas, thresholds, evidence IDs,
   policy gates and prohibited categories are code. Model output is an untrusted suggestion that
   must pass schema validation and the policy gate.
2. **Billing-only data never yields RESIZE, DELETE, STOP or BUY COMMITMENT.** Live categories are
   INVESTIGATE, REQUEST EVIDENCE, MONITOR and ESCALATE only.
3. **Invalid numbers are rejected, never converted to zero.**
4. **Model keys are server-side only**, read by the Python worker. The web app never sees them.
5. **No hidden model substitution.** If Jev is disabled, unconsented or failing, the finding shows
   deterministic facts plus a human-review state.
6. **Tenant isolation.** Every table has `tenant_id`; access goes through one scoping chokepoint and
   Postgres RLS.

## Layout

```
apps/web/        Next.js (App Router, TypeScript, Tailwind) — landing, form, upload, snapshot, admin
packages/domain  Zod schemas shared by the web app
packages/config  Shared constants
worker/          Python 3.12 worker — parsing, analysis, evidence packets, Jev, policy gate
db/migrations    SQL migrations (generated by Drizzle Kit)
fixtures/        Synthetic billing exports for tests
docs/            Product spec, ADRs, security, local development, deployment
```

## Getting started

See [`docs/local-development.md`](docs/local-development.md). The whole product runs locally with
**no cloud accounts and no API keys**: local file storage, a mock Jev provider and a dev inbox for
login links.
